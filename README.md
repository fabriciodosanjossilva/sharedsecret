# Shared secret
Split text into tokens and recover it with a subset of tokens.

# Features

- **100% local and private** — everything runs in your browser. No account, no server, no upload: your secret never leaves your device.
- **Split a secret into tokens** — turn any text into multiple tokens using Shamir's Secret Sharing.
- **Require a minimum number of tokens** — choose how many tokens are needed to recover the secret, so no single token reveals anything on its own.
- **Share tokens through different channels** — send each token to a different person or over a different medium.
- **Integrity protection** — tokens carry a checksum, so corrupted, mixed, or tampered tokens are detected before you trust the recovered text.
- **Recover from pasted tokens** — paste the tokens (one per line or all at once) and get the original text back.
- **QR codes for easy transfer** — show any token as a QR code or scan tokens with your camera.
- **Privacy-minded display** — tokens and recovered text are masked on screen and hide automatically after a short timeout.
- **No installation required** — a single HTML file that works offline from your computer.
